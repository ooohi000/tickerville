# 기획 명세

## 목표
관심 기업들이 **실제로 어디에 있는지** 3D 미국 지도 위에서 보고, 클릭하면 내 분석을 볼 수 있는 앱.
포트폴리오 겸 실사용. 개발 과정은 매주 velog에 연재.

## 화면 요소
| 요소 | 내용 |
|---|---|
| 지도 | 실제 미국 주 경계를 extrude한 3D 지형 (`geoAlbersUsa`, 알래스카·하와이 포함) |
| 건물 | 본사 위치에 배치. 시총 등급별 모양이 다름 |
| 티커 | 건물 위 티커 아이콘/라벨 |
| 클러스터 | 멀리서: 시총 1위 건물 + "+N" 배지 + 지역 이름표 |
| 목록 | 데스크톱 호버 / 모바일 탭 → 시총순 상위 5~6개 + 더보기 |
| 선택 | 목록 클릭 → 카메라 줌인 + 건물 하이라이트. 직접 줌인하면 자연스럽게 펼쳐짐 |
| 하늘 | CNN 공포·탐욕 지수 → 날씨 (공포=먹구름, 탐욕=맑음) |
| 땅 | 기업별 매수 관심도(`interest`) → 건물 주변 색 강도 |

만들지 않는 것: 등락률 표시.

## 데이터 계약
타입 원본은 `src/types/index.ts`.

- `companies.json`: `{ asOf, companies: Company[] }`
- `fearGreed.json`: `FearGreed` — 지수 스냅샷 (현재 샘플)
- `regions.json`: `Region[]` — 중심 위경도 + 반경(km). 반경 안의 본사가 그 지역에 묶인다.
- 시총은 스냅샷이며 `asOf`에 기준일을 적는다. 현재 값은 **샘플**이라 실제 값으로 갱신 필요.

## 규칙 값
| 항목 | 값 |
|---|---|
| 시총 등급 | mega ≥ $200B · large ≥ $10B · mid ≥ $2B · small 그 외 (`TIER_RANGES`) |
| 건물 | 등급별 모양: small=집(박공) · mid=평지붕 · large=안테나 · mega=첨탑 (`BUILDING_SPECS`). 같은 등급 안에서는 시총 로그 위치로 높이만 최대 1.5배 |
| 투영 | `geoAlbersUsa().scale(140).translate([0,0])` → 본토 폭 약 100 단위 |
| 지역 소속 | 본사–지역 중심 거리 ≤ `radiusKm` (경계 포함). 겹치면 더 가까운 지역 |
| 클러스터 | 소속 기업 `MIN_CLUSTER_SIZE`(=2) 이상 → 대표 건물 + "+N" + 목록. 1개여도 지역 이름표는 표시 |
| 날씨 | 0–24 storm(극단적 공포) · 25–44 rain(공포) · 45–55 cloudy(중립) · 56–75 partlyCloudy(탐욕) · 76–100 sunny(극단적 탐욕). 범위 밖은 0~100으로 자름. 화면 값은 `WEATHER_SPECS` |
