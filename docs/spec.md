# 기획 명세

## 목표
관심 기업들이 **실제로 어디에 있는지** 3D 미국 지도 위에서 보고, 클릭하면 내 분석을 볼 수 있는 앱.
포트폴리오 겸 실사용. 개발 과정은 매주 velog에 연재.
**공개 가능한 무료 데이터(SEC 공시 원본, 연준 공개 지표)만으로 만든다** — 월 비용 $0, 주가·시총·거래량은 보여주지 않는다 (`docs/data-sources.md`).

## 화면 요소
| 요소 | 내용 |
|---|---|
| 지도 | 실제 미국 주 경계를 extrude한 3D 지형 (`geoAlbersUsa`, 알래스카·하와이 포함) |
| 건물 | 본사 위치에 배치. **건물 높이 기준**(토글: 매출 · 순이익 · 총자산 · 공시상 시총)의 등급별로 모양이 다름. 기본은 매출 |
| 크레인 | 매출 성장률(전년 대비) +25% 이상인 **고성장 기업** 옆에 공사 크레인. 팔이 옥상 위에서 천천히 흔들림 |
| 티커 | 옥상 간판 (항상 카메라를 향함, Bebas Neue). 로고는 나중에 `logoUrl?`로 확장 |
| 클러스터 | 멀리서(카메라 거리 > `DETAIL_DISTANCE`): 현재 기준 1위 건물만 + 간판 "+N" 배지. 가까이: 멤버 건물·간판이 실제 위치에 나타나고 배지는 사라짐. 지역 이름표는 항상 (HTML, 한글) |
| 목록 | 지역 이름표에 데스크톱 호버 / 모바일 탭 → 현재 기준순 상위 5개(그 지표 값 + 고성장이면 성장률) + 더보기. 모바일은 아래 시트, 넓은 화면은 오른쪽 패널. 항목 누르면 건물 선택(하이라이트) |
| 선택 | 목록 클릭 → 카메라 줌인 + 건물 하이라이트. 직접 줌인하면 자연스럽게 펼쳐짐 |
| 하늘 | 자체 **시장 날씨 지수**(0~100, 금융스트레스 지수의 최근 10년 백분위) → 날씨 (불안=먹구름·비·번개, 안정=맑음). 왼쪽 위에 지수·구간 표시. 개발용 `?mw=숫자`로 날씨 미리보기. CNN 공포·탐욕은 공식 API가 없어 쓰지 않음 |
| 시계 | 왼쪽 맨 위. 장 상태(프리마켓·정규장·애프터마켓·장 마감, 휴장·조기 폐장 사유) + 다음 변화까지 남은 시간 + 뉴욕·서울 시각. NYSE 공식 휴장 일정(`marketCalendar.ts`). 개발용 `?now=2026-11-27T12:00-05:00`로 시각 고정 |
| 땅 | **최근 30일 공시 활동**(`filings30d`: 중요 사건 8-K + 내부자 거래 Form 4) → 건물 주변 원판("열기")의 진하기·크기. "요즘 이 회사에 일이 많다" |

만들지 않는 것: 등락률·주가·시총·거래량 표시 (라이선스 비용). 시세가 궁금한 방문자에겐 외부 시세 페이지 **링크만** 제공.

## 데이터 계약
타입 원본은 `src/types/index.ts`.

- `companies.json`: `{ asOf, companies: Company[] }`
- `marketWeather.json`: `MarketWeather` — 시장 날씨 지수 스냅샷 (현재 샘플)
- `regions.json`: `Region[]` — 중심 위경도 + 반경(km). 반경 안의 본사가 그 지역에 묶인다.
- 매출·공시 건수는 스냅샷이며 `asOf`에 기준일을 적는다. 계산 규칙은 `docs/api.md`. 현재 값은 **샘플**(대략적인 값)이라 서버 연결 후 실제 값으로 바뀐다.

## 규칙 값
| 항목 | 값 |
|---|---|
| 규모 등급 | 지표별 경계는 `SIZE_METRICS` (`sizeMetric.ts`). 매출: mega ≥ $100B · large ≥ $10B · mid ≥ $1B · small 그 외. 값 없음·적자는 small |
| 고성장 | 매출 성장률 ≥ +25% (`HIGH_GROWTH_THRESHOLD`) → 크레인 |
| 건물 | 등급별 모양: small=집(박공) · mid=평지붕 · large=안테나 · mega=첨탑 (`BUILDING_SPECS`). 같은 등급 안에서는 지표 값의 로그 위치로 높이만 최대 1.5배 |
| 투영 | `geoAlbersUsa().scale(140).translate([0,0])` → 본토 폭 약 100 단위 |
| 지역 소속 | 본사–지역 중심 거리 ≤ `radiusKm` (경계 포함). 겹치면 더 가까운 지역 |
| 클러스터 | 소속 기업 `MIN_CLUSTER_SIZE`(=2) 이상 → 대표 건물 + "+N" + 목록. 1개여도 지역 이름표는 표시 |
| 날씨 | 0–24 storm(매우 불안) · 25–44 rain(불안) · 45–55 cloudy(보통) · 56–75 partlyCloudy(안정) · 76–100 sunny(매우 안정). 범위 밖은 0~100으로 자름. 화면 값은 `WEATHER_SPECS` |
| 땅 열기 | 점수 = 8-K × 3 + Form 4 × 1. 4 이하 없음 ~ 48 이상 최대, 로그 스케일 (`eventHeat.ts`) |

## 단계
1. **클라이언트 전용**: 정적 JSON + 3D 화면 (화면 다듬기만 남음)
2. **서버** (진행 중): 스프링부트 + PostgreSQL + Redis, 같은 레포 `server/`. SEC(재무제표·공시)와 FRED·수출입은행(시장 날씨·매크로)을 매일 수집·정규화, 조회 API. 계약은 `docs/api.md`
3. 기업 상세 화면(재무제표, 분석 글), 검색·스크리닝
