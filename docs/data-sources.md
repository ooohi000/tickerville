# 데이터 소스 조사 (2026-10-19)

> 가격·약관은 조사일 기준. 바뀔 수 있으니 결제·공개 전 공식 페이지에서 다시 확인.
> 법률 자문 아님 — 공개 표시 권한은 각 제공처에 **서면으로** 확인하는 게 안전하다.

## 한 줄 결론
- **재무제표·금리·환율·유가·천연가스는 무료로 공개 가능** (SEC, FRED의 공공 데이터, 한국수출입은행)
- **주가·시총·거래량, 금·은 일별, VIX, CNN 공포·탐욕은 "공개 사이트에 보여주는 것"에 라이선스가 걸린다**
- 거의 모든 주가 API의 개인 요금제는 "본인만 보는 용도"라서, 방문자가 보는 순간 사업자/표시 라이선스가 필요하다

## 2. 재무제표 — SEC EDGAR ✅ 무료
- API 키 없음, 무료. `companyfacts`(기업별 전체 XBRL 항목), `submissions`(공시 이력·주소) 등
- 공시 후 1분 안팎 반영, 대량용 zip은 매일 새벽 3시(미 동부) 갱신
- 규칙: **초당 10회 이하**, 요청 헤더에 `User-Agent: 앱이름 연락처이메일` 필수
- 할 일: 기업마다 다른 XBRL 항목명을 매출·영업이익 등으로 정규화하는 작업

## 3. 금리·환율·지표 — FRED ✅ 무료 (조건 있음)

## 6. CNN 공포·탐욕 지수 ❌
- **공식 API 없음.** 돌아다니는 방법은 CNN 사이트 내부 주소를 직접 긁어오는 것(브라우저인 척 위장까지 함) → 언제든 막힐 수 있고 약관 위반 위험
- CNN 지수는 7개 지표로 구성: S&P500 모멘텀, 52주 신고가/신저가, 상승·하락 거래량, 풋/콜 비율, 정크본드 스프레드, VIX, 주식 대비 국채 수익률
- **대안: 자체 "시장 날씨 지수"** — 우리가 표시 권한을 가진 데이터(라이선스 받은 주가로 계산한 모멘텀·신고가 비율·거래량 쏠림 + FRED 공공 금리차 등)로 직접 계산. 이름도 "공포·탐욕" 대신 자체 이름으로

- 주가 원본 숫자(종가)는 화면에 직접 보여주지 않고 **건물 높이·원판 색 같은 가공 표현만** 쓰는 방법 → 단, FMP처럼 "가공해도 라이선스 필요"인 곳도 있어서 제공처별 확인 필수
- 공개 데모는 **며칠 지난 데이터나 샘플**로 운영하고, 실시간에 가까운 데이터는 본인용으로만

## 추가 확인 (2026-10-19 오후)
- **FMP 공개 표시 = Enterprise 요금제만.** 가격 비공개(영업 문의). 개인 요금제(연간결제 월 $19/$49/$99)로는 공개 불가 → 공개용으론 부적합
- **재무제표는 SEC를 원본으로.** 무료·공개 가능·원본이라 날짜가 정확하다. 정리된 API는 회계연도 기준을 섞어 쓰면 날짜가 어긋나 보일 수 있다
  - SEC 함정: `companyfacts`의 `fy`·`fp`는 **그 값이 실린 공시의** 회계연도·분기다. 10-K에 같이 실린 전년도 비교값도 같은 `fy`를 단다 → 기간은 반드시 `start`·`end` 날짜로 판정하고, 같은 기간이 여러 공시에 나오면 `filed`가 최신인 값(정정 반영)을 쓴다
- 바뀐 추천: 재무제표·발행주식수 = SEC, 주가·거래량 = 공개 표시 가능한 저가 제공처(Marketstack 확인), FMP는 쓰지 않거나 개발 중 교차 검증용
